# AGENTS.md

## Project context

This is a TanStack Start application using React 19 and plain JavaScript. Read `README.md` for local setup and deployment.

## Key files

- `src/routes/__root.jsx` defines the HTML document and shared route components.
- `src/routes/*.jsx` contains file-based pages.
- `src/lib/server-fns.js` contains server functions used by pages.
- `src/start.js` configures the TanStack Start instance.
- `src/server.js` is the Cloudflare Worker entry point.
- `vite.config.js` configures the Cloudflare, TanStack Start, and React Vite plugins.
- `src/routeTree.gen.ts` is generated by the router plugin; do not edit it manually.

## Server code

- Server functions are public HTTP endpoints. Validate every input and do not rely on page-level navigation or UI controls for access control.
- Keep secrets in Worker environment bindings, read them only in server code through `cloudflare:workers`, and never expose them through `import.meta.env`.
- Use `.dev.vars` for local Worker secrets; configure production secrets with Wrangler.
- Keep retries and other potentially unbounded work explicitly capped.

## Development

- Run `npm run dev` for local development.
- Run `npm run lint` before finishing code changes.
- Run `npm run build` to validate the production Worker build.
- Write application code in JavaScript and JSX. Do not edit generated route files.
- Keep the Cloudflare, TanStack Start, and React plugins in `vite.config.js`.
